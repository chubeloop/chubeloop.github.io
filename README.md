# chubeloop-prof-template

A GitHub Pages template adapted to match the overall structure and look of Professor Chanjun Park's academic homepage.

## Included pages

- `index.md` - main homepage
- `cv.md` - CV / profile summary page
- `contact.md` - simple contact page
- `_config.yml` - site title and navigation

## How to use

1. Back up the contents of your existing `chubeloop.github.io` repository.
2. Replace the repository contents with the files in this template.
3. Commit and push to GitHub.
4. Wait a minute or two for GitHub Pages to rebuild.

## What to customize next

- Replace the biography with your preferred wording.
- Add your institutional email in `contact.md`.
- Replace the CV page with a real PDF if you want.
- Add publications, awards, talks, and projects as they become public.

## Notes

- The profile image currently uses your GitHub avatar: `https://github.com/chubeloop.png`
- The site keeps the `researcher`-style layout locally through `_layouts`, `_sass`, and `css`.
